# SoundMatch Live — Fast Cash Plan

## Objective

SoundMatch Live is not being built only as a long-term startup. The immediate objective is to turn the prototype into a commercial asset that can produce money as quickly as possible.

Money can come from any of these routes:

1. Paid pilot
2. White-label licence
3. Direct subscription launch
4. Asset sale / acquisition
5. Partnership with an organisation that already has music industry reach

The creator does not need to personally operate the platform forever.

## Fastest likely route

The fastest route is not a public consumer launch. The fastest route is a paid pilot or white-label offer to an organisation that already has users and budget.

Priority buyers:

1. Music schools and universities
2. Venues and venue groups
3. Promoter networks
4. Festivals
5. Artist development organisations
6. Booking agencies and managers
7. Artist service platforms

## Commercial positioning

Do not pitch this as a giant global social network.

Pitch it as:

> A ready-to-adapt EPK, artist discovery and booking request platform for music schools, venues, promoters, festivals and artist networks.

Shorter version:

> A white-label booking and EPK system for live music ecosystems.

## What the buyer understands immediately

A buyer does not need to understand the full marketplace vision. They only need to understand that the product solves existing pain:

- Artists need better EPK/profile pages.
- Promoters lose time searching through DMs, Instagram, spreadsheets and messy emails.
- Venues need local talent pipelines.
- Music schools need graduate employability tools.
- Festivals need shortlist and booking workflows.
- Agencies need roster presentation and inbound booking requests.

## Minimum buyer-ready MVP

Before serious outreach, the app needs the following:

- Public deployed demo
- Clean landing page
- Public EPK/profile pages
- Booking request form
- Inbox/request dashboard
- Organisation/admin dashboard mock
- 20–50 credible demo or real artist/venue/promoter profiles
- Short explainer video
- One-page PDF pitch deck
- Clear commercial packages

## Build priority

Build only what helps selling, licensing or launching.

### Must build now

- Landing page aimed at buyers
- Public profile/EPK page
- Booking request flow
- Request inbox/dashboard
- Organisation dashboard mock
- Pricing/licensing page or section
- Demo dataset that looks credible

### Do not build yet

- Complex chat
- Native mobile app
- Algorithmic matching
- Social feed
- Advanced calendar
- Deep AI recommendations
- Complex multi-sided marketplace operations

These can come later only if they help close money.

## Commercial packages

### Package A — Paid pilot

For music schools, venues, festivals, promoters or cultural organisations.

Offer:

- Branded demo environment
- 20–50 profiles imported
- Booking/EPK workflow
- Admin dashboard
- 1–3 month pilot
- Feedback/report at the end

Suggested price:

- Small pilot: £1,500–£3,000
- Strong pilot: £3,000–£10,000

### Package B — White-label licence

For organisations that want their own branded version.

Offer:

- Custom branding
- Private profile network
- Booking request workflow
- Organisation dashboard
- Setup + monthly support

Suggested price:

- Setup: £5,000–£25,000
- Monthly maintenance: £300–£2,000+

### Package C — Direct app monetisation

For public launch if buyer route is slower.

Possible prices:

- Artist Pro: £9/month or £79/year
- Promoter/Venue Pro: £29–£99/month
- Featured profile: £20–£50 one-off
- Organisation dashboard: £199–£499/month

### Package D — Asset sale

Sell the codebase, brand, concept, roadmap, demo assets and any validation.

This becomes stronger after:

- A working MVP exists
- A few real users/profiles exist
- At least one organisation shows interest
- A buyer can see how to monetise or integrate it

## 14-day execution sprint

### Day 1–2

Refactor the prototype enough to make it easier to extend. Keep the design. Do not over-engineer.

### Day 3–4

Add landing page structure and buyer-facing commercial language.

### Day 5–6

Add public EPK/profile page.

### Day 7–8

Add booking request flow and dashboard mock.

### Day 9–10

Add organisation/admin dashboard mock and demo profiles.

### Day 11

Create one-page pitch deck.

### Day 12

Create short demo video script and record/sendable demo.

### Day 13–14

Start outreach to 30–50 targeted buyers.

## First outreach targets

Start with people closest to existing credibility:

- London music education institutions
- Underground promoters
- Venues with live/electronic programming
- Festivals and cultural organisations
- Artist development networks

## Success condition

The project succeeds if money arrives through any route:

- paid pilot
- white-label setup
- direct subscription
- featured listing
- commercial partnership
- asset sale

The goal is not to prove a perfect startup theory. The goal is to make the prototype economically useful as quickly as possible.
