# SoundMatch Live MVP

Independent Vite React prototype for SoundMatch Live, a global live music booking marketplace.

Core UX:

- Swipe discovery for artists, venues, promoters, festivals and agents
- Right swipe means interested
- Left swipe means pass
- Mutual interest creates a match
- Match opens chat
- Booking is confirmed only after structured terms
- Artist EPK
- Match inbox
- Booking request workflow
- Booking detail with chat and terms summary
- Global demo data
- Dark backstage pass visual direction

## Run locally

npm install
npm run dev

Open http://localhost:5173

## Build

npm run build

## Deploy

Framework: Vite
Build command: npm run build
Output directory: dist
Install command: npm install

## Current status

Frontend MVP with local demo state only. Backend, auth and production persistence come later.
